# 微光

微光成长社的情绪记录与回看 PWA，可安装到手机主屏幕。

## GitHub Pages 发布

1. 在 GitHub 新建一个公开仓库。
2. 上传本项目根目录里的文件和 `icons` 文件夹。
3. 进入仓库 `Settings` -> `Pages`。
4. `Build and deployment` 选择 `Deploy from a branch`。
5. `Branch` 选择 `main` 和 `/root`，保存。
6. 等待 GitHub Pages 生成 HTTPS 地址。

## 离线使用

手机打开 GitHub Pages 的 HTTPS 地址后，先联网打开一次应用，并停留 10 秒左右，让离线缓存完成安装。

如果之前安装过旧版本，先删除手机桌面图标，再重新打开 HTTPS 地址并添加到主屏幕。
